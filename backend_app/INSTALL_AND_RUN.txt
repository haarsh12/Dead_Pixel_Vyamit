═══════════════════════════════════════════════════════════
STEP 1: INSTALL DEPENDENCIES (in venv)
═══════════════════════════════════════════════════════════

Run this command:
pip install -r requirements.txt

This will install all packages into your venv.

═══════════════════════════════════════════════════════════
STEP 2: START SERVER (correct command)
═══════════════════════════════════════════════════════════

DO NOT USE: python -m uvicorn app.main:app
            (This is wrong - no 'app' folder!)

USE THIS INSTEAD:
python main.py

OR:
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

═══════════════════════════════════════════════════════════
