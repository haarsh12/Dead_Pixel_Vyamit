📝 DETAILED STEPS
═══════════════════════════════════════════════════════════

STEP 1: Install Dependencies
────────────────────────────────────────────────────────────
Command:
  pip install -r requirements.txt

What it does:
  - Installs FastAPI, Uvicorn, SQLModel, etc.
  - Installs into your venv (already activated)
  - Takes ~2 minutes

STEP 2: Configure .env File (ONE TIME)
────────────────────────────────────────────────────────────
Edit: backend_app\.env

Required changes:
  Line 8:  Replace YOUR_DATABASE_PASSWORD with Supabase password
  Line 26: Generate SECRET_KEY:
           python -c "import secrets; print(secrets.token_urlsafe(32))"
  Line 35: Add GEMINI_API_KEY from Google AI Studio

STEP 3: Enable pgvector in Supabase (ONE TIME)
────────────────────────────────────────────────────────────
1. Go to: https://supabase.com/dashboard/project/jpnwbzdkyvaexexkwprv/sql
2. Run: CREATE EXTENSION IF NOT EXISTS vector;

STEP 4: Start Server
────────────────────────────────────────────────────────────
Command:
  python main.py

Alternative:
  uvicorn main:app --reload

You'll see:
  INFO:     Uvicorn running on http://0.0.0.0:8000
  INFO:     Application startup complete.

STEP 5: Test API
────────────────────────────────────────────────────────────
Open: http://localhost:8000/docs

Try: GET /health
Response: {"status": "ok"}

❌ COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════

ERROR: "No module named uvicorn"
FIX:   pip install -r requirements.txt

ERROR: "No module named 'app'"
FIX:   Use: python main.py
       NOT: python -m uvicorn app.main:app

ERROR: "DATABASE_URL not set"
FIX:   Edit .env file, update DATABASE_URL password

ERROR: "pgvector not found"
FIX:   Run in Supabase SQL: CREATE EXTENSION IF NOT EXISTS vector;

ERROR: "Port 8000 already in use"
FIX:   Edit .env, change PORT=8001
