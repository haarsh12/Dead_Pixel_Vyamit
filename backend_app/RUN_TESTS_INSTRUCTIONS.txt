TROUBLESHOOTING
===============

If Gemini 404 errors persist:
1. Check API key: echo %GEMINI_API_KEY%
2. Test in browser: https://ai.google.dev
3. Verify you have access to text-embedding-004
4. Check quota limits

If Mistral import fails:
1. Update package: pip install --upgrade mistralai
2. Check version: pip show mistralai
3. Mistral is optional - tests will pass with Gemini only

If database errors:
1. Check DATABASE_URL in .env
2. Verify PostgreSQL is running
3. Check pgvector extension installed

If all tests fail:
1. cd backend_app
2. python verify_fixes.py
3. Check .env file exists
4. Activate virtual environment if needed
