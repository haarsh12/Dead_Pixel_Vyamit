🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

❌ "Connection refused" or "Failed to connect"
──────────────────────────────────────────────────────────
1. Check backend is running (python main.py)
2. Check your PC firewall allows port 8000
3. Verify phone and PC on same WiFi network
4. Check IP address hasn't changed:
   Run: ipconfig
   Look for: IPv4 Address
   Update in config.dart if different

❌ Backend not accessible from phone
──────────────────────────────────────────────────────────
1. Test from PC first: http://localhost:8000/docs
2. Test from PC with IP: http://192.168.110.207:8000/docs
3. If #2 fails, check Windows Firewall:
   - Open Windows Defender Firewall
   - Allow Python through firewall
   - Or temporarily disable for testing

❌ IP Address changed
──────────────────────────────────────────────────────────
Your IP might change if:
- You reconnect to WiFi
- Router assigns new IP
- You switch networks

To fix:
1. Run: ipconfig
2. Find new IPv4 Address
3. Update frontend_app/lib/core/config.dart line 10:
   static const String _realDeviceUrl = "http://NEW_IP:8000";
