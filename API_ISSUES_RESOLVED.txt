Issue 1: POST /auth/send-otp → 422 Unprocessable Entity
---------------------------------------------------------
FROM: 192.168.110.144 (Flutter app)

ROOT CAUSE:
Flutter app is sending phone number that doesn't pass validation.

VALIDATION REQUIREMENTS:
- Must be 10-15 characters
- Must be valid Indian mobile number (starts with 6-9)
- Accepted formats:
  ✅ "9876543210"
  ✅ "+919876543210"  
  ✅ "919876543210"

COMMON INVALID FORMATS:
❌ "1234567890" (doesn't start with 6-9)
❌ "+11234567890" (wrong country code)
❌ "98765" (too short)
❌ " 9876543210 " (has spaces - needs trim)
❌ "(987) 654-3210" (has special chars)

SOLUTION - Flutter App Fix:
---------------------------
The phone number needs to be cleaned before sending:

1. Remove spaces, dashes, parentheses
2. Remove country code if not +91
3. Ensure it's 10 digits starting with 6-9
4. Add validation in UI before API call

Example Fix:
```dart
String cleanPhoneNumber(String phone) {
  // Remove spaces and special characters
  String cleaned = phone.replaceAll(RegExp(r'[\s\-\(\)]'), '');
  
  // Remove + if present
  if (cleaned.startsWith('+')) {
    cleaned = cleaned.substring(1);
  }
  
  // If starts with 91, remove it
  if (cleaned.startsWith('91') && cleaned.length == 12) {
    cleaned = cleaned.substring(2);
  }
  
  // Validate: must be 10 digits starting with 6-9
  if (!RegExp(r'^[6-9]\d{9}$').hasMatch(cleaned)) {
    throw Exception('Invalid phone number');
  }
  
  return cleaned;
}

// Usage:
Future<void> sendOtp(String phone, bool isLogin) async {
  try {
    String cleanedPhone = cleanPhoneNumber(phone);
    await _apiClient.post('/auth/send-otp', {
      "phone_number": cleanedPhone,
      "is_login": isLogin
    });
  } catch (e) {
    rethrow;
  }
}
```

Future<dynamic> get(String endpoint, {Map<String, String>? headers}) async {
  final token = await _storage.read(key: 'token');
  
  final response = await http.get(
    Uri.parse('$baseUrl$endpoint'),
    headers: {
      if (token != null) 'Authorization': 'Bearer $token',
      'Content-Type': 'application/json',
      ...?headers,
    },
  );
  
  // Handle auth errors
  if (response.statusCode == 401 || response.statusCode == 403) {
    await _handleAuthError();
    throw Exception('Session expired. Please login again.');
  }
  
  if (response.statusCode >= 400) {
    throw Exception(jsonDecode(response.body)['detail'] ?? 'Request failed');
  }
  
  return jsonDecode(response.body);
}
